# Tokai Studio

안경원 상담을 위한 시야 체험 및 렌즈 상담 프로그램입니다.

굴절 상태와 시야 변화를 시뮬레이션하고, 다양한 렌즈의 특징을 비교·체험할 수 있습니다.

## 다운로드

👉 [Tokai Studio 설치파일 다운로드](https://github.com/stackop/tokaistudio-release/releases/latest/download/Tokai.Studio_Installer.exe)

Windows용 설치파일을 다운로드할 수 있습니다.

설치 후 프로그램 실행 시 필요한 업데이트가 자동으로 진행됩니다.

## 지원 환경

* Windows 10 / 11
* 64-bit

## 설치 방법

1. 위의 **Tokai Studio 설치파일 다운로드**를 클릭하여 설치파일을 다운로드합니다.
2. 다운로드한 설치파일을 **우클릭**하고 **속성**을 선택합니다.
3. 속성 창 하단의 **보안** 항목에서 **차단 해제**를 체크한 후 **확인**을 누릅니다.
4. 설치파일을 실행하여 Tokai Studio를 설치합니다.
5. 설치가 완료되면 Tokai Studio를 실행합니다.
6. 필요한 경우 프로그램 업데이트가 자동으로 진행됩니다.

> **참고:** `차단 해제` 항목이 표시되지 않는 경우에는 별도의 설정 없이 설치파일을 실행하면 됩니다.

## 업데이트

Tokai Studio는 프로그램 실행 시 새로운 업데이트를 확인합니다.

* **필수 업데이트**가 있는 경우 자동으로 업데이트가 진행됩니다.
* 그 외 업데이트는 프로그램의 **설정 → 업데이트**에서 직접 확인하고 진행할 수 있습니다.
